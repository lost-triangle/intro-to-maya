# Modelling: Polygon

Ein Polygon ist eine durch eine endliche Anzahl von geraden Linien aufgebaute Figur. Man benötigt mindestens 3 Linien bzw. 3 Punkte, um eine Ebene aufzuspannen und damit ein Polygon-Objekt zu erzeugen.

Bei Polygon-Objekten müssen Dinge wie Edge Flow, ausschließliche Quad-Geometrie usw. beachtet werden.
